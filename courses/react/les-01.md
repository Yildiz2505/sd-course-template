# Les 1 – Voorbeeldles React

## 🎯 Leerdoelen

Na deze les kun je:
- uitleggen wat een React-component is;
- een eenvoudige component herkennen;
- wijzigingen vastleggen op GitHub.

## 📖 Introductie

Welkom bij React Basis. Je bouwt in deze lessen aan een **Game Collection**.

## 💡 Theorie

Een component is een herbruikbaar onderdeel van de gebruikersinterface.

```jsx
function Header() {
  return <h1>Game Collection</h1>;
}
export default Header;
```

> [!NOTE]
> Deze pagina toont de les. De React-code voer je uit in je eigen project.

## 🛠️ Stap voor stap

1. Open je React-project.
2. Maak de component `Header`.
3. Laat de titel zien op de pagina.

> [!TIP]
> Componentnamen beginnen met een hoofdletter.

## ⚠️ Veelgemaakte fouten

> [!WARNING]
> Vergeet niet de component te importeren.
